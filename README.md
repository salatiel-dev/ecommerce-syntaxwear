# SyntaxWear

Projeto de landing page e-commerce para uma marca de tênis e sneakers, com foco em estética moderna, responsividade e experiência visual imersiva.

## 📌 Sobre o projeto

O SyntaxWear é uma página institucional e comercial desenvolvida em HTML e CSS, com uma estrutura organizada para apresentar:

- hero section com destaque de produtos
- categorias de produtos
- grid de cards promocionais
- header e footer estilizados
- layout responsivo para desktop e mobile

## 🛠️ Tecnologias

- HTML5
- CSS3
- Visual Studio Code

## 📁 Estrutura do projeto

- `index.html` — estrutura principal da página
- `css/` — arquivos de estilos organizados por componentes
- `img/` — imagens do projeto, incluindo logos, ícones e banners

## ▶️ Como executar

1. Abra a pasta do projeto no VS Code.
2. Clique com o botão direito no arquivo `index.html`.
3. Selecione a opção "Open with Live Server".

Se o Live Server não estiver instalado, você pode abrir o arquivo diretamente no navegador.
